# Como contribuir

Obrigado pelo interesse no `py-eye`! Para manter o projeto saudável e fácil de mexer, siga essas orientações rápidas.

## Fluxo recomendado

1. Fork o repo e crie uma branch com nome curto:
```bash
git checkout -b feat/nova-expressao
```

2. Faça alterações pequenas e com propósito.
3. Rode o projeto localmente para validar antes do commit.
4. Abra um Pull Request descrevendo o que mudou e por quê.

## Dicas

- Use mensagens de commit diretas: `feat: adiciona expressao dizzy`
- Se mudar `eye.py`, evite edições massivas sem necessidade.
- Se adicionar assets, coloque em `scr/` ou `sound/generated/` conforme o tipo.

## Código de conduta

Seja direto, respeitoso e prático. Não preciso de formalidade excessiva — só de código que funcione.
